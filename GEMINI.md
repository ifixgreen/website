# AI Assistant Guidelines for iFix Green Solutions Website

## 🚨 MANDATORY RULES

### 1. Always Read `README.md` First
- **Before beginning ANY task**, query, bug fix, feature development, or configuration change, you **MUST always read `README.md`** first.
- This ensures you are fully aware of current architecture, live infrastructure (DNS, email routing, domain setup), project structure, and the latest entries in the work log.

### 2. Always Update `README.md` Work Log
- Whenever you perform **ANY** task, fix, feature, modification, or configuration change:
  - Locate the `## 📜 Complete Work & Change Log` section in `README.md`.
  - Add a bullet point entry under today's date summarizing the changes made, files touched, or infrastructure updated.
  - Maintain reverse chronological order (newest dates at the top).

### 3. Commit and Push
- Ensure `README.md` is committed and pushed to GitHub (`main` branch) together with your code changes, ensuring documentation is always in sync across local and remote repositories.
